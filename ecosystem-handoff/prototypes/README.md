# 编辑器交互草图的用途

editor-concept.html 是前面讨论时制作的 HTML/SVG 交互概念草图，此次保留以方便理解笔刷放置、对象选择/移动、撤销以及林下/浅塘草稿切换。它是资料中的历史原型，不是正式产品实现。

可以参考其中的操作意图，但正式项目仍按 React、PixiJS、Rust 和 Tauri 的职责重新设计。草图中的形状、配色、对象尺寸、快捷键或数据结构不自动成为正式规范。

草图不包含真实生态内核，不代表多世界运行、睡眠恢复、资源守恒或正式存档已经完成。正式画风以 references 原图及 docs/08-visual-and-asset-guide.md 为依据，不能用草图的视觉简化替代用户对画质的期望。

前序工作只进行过源码和脚本语法层面的检查；未据此宣称通过 Windows 实机交互或像素视觉验收。Codex 首轮可阅读源码核对意图，工程验证在开工授权后的对应里程碑完成。
