# 现状观察、影响与证据边界

这里列的是当前发行版中观察到的表现。界面观察与代码事实分开写。后续选定的「像素工作台」仅作为背景，这份资料没有确定新的布局、配色或交互规则。

## 本次实际观察

## 代码可核对，实际覆盖有边界

- Windows 托盘的主菜单和组件子菜单由 Rust/Tauri 构建。Windows 窗口捕获工具可返回编辑器 Alt+Space 系统菜单，但没有取得托盘／通知区本身可操作的句柄。本轮从既有原生显示命令打开窗口，并经工作区保存命令准备三种组件状态。托盘点击与勾选属于未实测入口。最短补法是在启动隔离实例后，于任务栏通知区展开隐藏图标，右击「微缩生态」，分别截取主菜单与「组件」子菜单的本体，避免截入整张桌面。
- 面板透明像素和卡片之间的留空在窗口捕获中可见。窗口捕获不证明该像素能把指针传给后面的桌面，也不证明顶层窗口关系。最短补法是在无私人内容的桌面区域放置另一可测试窗口，分别点击卡片、间隙和面板外部并记录接收者。组件常态是否始终在最上层、混合 DPI/跨屏和最小化原生焦点也需要独立操作取证。
- 试运行的冲突报告、首次加载错误、渲染失败、世界绑定不可用、损坏检查点、挂起等有部分代码入口。本轮现场没有触发这些状态。隔离写入失败已用既有方法验证并恢复，不作为其他异常的替代证据。需要补冲突时先复制独立会话，以现有 M4 模式逐项制造可控的修订变化，再复拍；避免改动正式世界。
- 本次实际移动石块、在浅塘校验与补水、投放两种主题的初始组、恢复、采用、归档及退出。素材搜索／无搜索结果、画笔、逐物种增删、单组件独立原生窗口、手动锁定、显式穿透开关、持续试运行播放等当前没有对应产品入口。细项含不存在与未到达的区分见界面清单。

## 图像与环境说明

Windows 原生 WebView2 原图为完整客户区 PNG。Windows.Graphics.Capture 另外保留窗口和系统菜单的工具输出 JPEG，两者以证据方式明确区别。PNG 未缩放；WGC 工具可能以其逻辑像素输出 JPEG。未提供全桌面截图或录屏，流程用原图顺序代替。所有已捕获的世界为同一次独立采集建立，未使用用户现有数据。自然运行的世界以原样保留，相关权威步数与预览状态见逐图账本。
