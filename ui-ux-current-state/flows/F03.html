F03 试运行与回写

开启和推进试运行副本，检查丢弃与采用结果的不同后果。

步骤操作和结果证据
从编辑进入W01 处于编辑暂停，点「试运行」。原来的保存和编辑控制换成试运行工具，画布出现副本标识。UI-022
推进并查看选 10× 后点「推进 20 模拟秒」。界面报告本批增加的时间及生态变化。倍率选择和实际推进是两步。UI-023
返回在 W01 看过「采用结果」与「另存为世界」的独立确认／输入面板后均取消，再点「丢弃副本」，返回原世界的编辑暂停。UI-024、UI-025、UI-026
实际采用仅在独立的 W03 中另开试运行，推进 60 秒后点「采用结果」「采用并保存」。提示说明目标世界，采用后回到 W03 正式编辑状态，保存相应进度。UI-039、UI-040
区分暂停语义从生活中进入编辑后，「完成编辑，开始生活」回到运行。先人工暂停再进编辑时，按钮改为「完成编辑」，完成后页脚提示保留原先手动暂停。UI-027、UI-028

UI 提供手动分批推进，没有播放/连续暂停按钮。试运行另存的表单实际打开，未提交。未注入冲突；服务端存在分支基线校验，详见实现图。
