F01 启动到观赏

启动组件，打开世界库，进入已有世界，查看信息并返回观赏。

步骤操作和结果证据
起点新的数据目录启动后直接显示组件。等到采集工具连接时，默认闲置覆盖已出现。编辑器通过同一原生显示入口打开。UI-001、UI-002
进入世界库在编辑器顶部点「世界库」。在初始状态里只看到当前林下，世界库是模态框，其他编辑控件不可直接使用。UI-003
切回已有世界先新建浅塘及空白副本，再从列表点击林下的「打开」。标题回到「林下切片」，W01 原先的暂停设置保留。没有另起一份同名生态。UI-045
查看对象和环境右栏首段显示林下对象和指标。进入编辑并「选择石块」后出现「石块位置」。将右栏折叠项展开后滚动到季节和日照，地点表单可见。UI-011、UI-015、UI-016、UI-017
返回观赏观赏窗只显示场景及少量状态。林下有未覆盖画面。浅塘依次保留闲置覆盖、聚焦后淡出过程、覆盖完全消失的三个实际状态。UI-007、UI-034、UI-064、UI-072

实际使用时入口在托盘。托盘项名称和对应窗口见实现定位图。本轮直接打开原生窗口做后续操作，未核实 Windows shell 上的托盘菜单点击路径。
