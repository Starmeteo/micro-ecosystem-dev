# 五条实际操作流程

图号对应 [原图索引](index.html) 和 [界面清单](screen-inventory.csv)。图中 `W01` 等为本资料的编号，应用只显示世界名称。流程使用隔离的 Windows 发行版。主要操作通过实际编辑器按钮、字段和原生指针完成；原生窗口首次打开和部分组件布局准备复用项目的原生命令。流程图为有序静态证据。

## F01 启动、已有世界和观赏

| 步骤 | 操作和结果 | 证据 |
| --- | --- | --- |
| 起点 | 新的数据目录启动后直接显示组件。等到采集工具连接时，默认闲置覆盖已出现。编辑器通过同一原生显示入口打开。 | UI-001、UI-002 |
| 进入世界库 | 在编辑器顶部点「世界库」。在初始状态里只看到当前林下，世界库是模态框，其他编辑控件不可直接使用。 | UI-003 |
| 切回已有世界 | 先新建浅塘及空白副本，再从列表点击林下的「打开」。标题回到「林下切片」，W01 原先的暂停设置保留。没有另起一份同名生态。 | UI-045 |
| 查看对象和环境 | 右栏首段显示林下对象和指标。进入编辑并「选择石块」后出现「石块位置」。将右栏折叠项展开后滚动到季节和日照，地点表单可见。 | UI-011、UI-015、UI-016、UI-017 |
| 返回观赏 | 观赏窗只显示场景及少量状态。林下有未覆盖画面。浅塘依次保留闲置覆盖、聚焦后淡出过程、覆盖完全消失的三个实际状态。 | UI-007、UI-034、UI-064、UI-072 |

实际使用时入口在托盘。托盘项名称和对应窗口见实现定位图。本轮直接打开原生窗口做后续操作，未核实 Windows shell 上的托盘菜单点击路径。

## F02 从预设新建、调整和保存

| 步骤 | 操作和结果 | 证据 |
| --- | --- | --- |
| 选择起点 | 在世界库切至「从预设新建」，从一个下拉框选林下、浅塘或空白，填写名称。新建 W02 后直接进入编辑暂停。内置、空白、个人预设共享创建表单。 | UI-004、UI-005、UI-006、UI-030 |
| 林下调整 | W01 的「编辑环境」进入编辑暂停。「选择石块」后在画布上用右方向键移动，右栏位置和页脚变化。随后点击撤销、重做。 | UI-010 至 UI-014 |
| 浅塘调整 | 在 W02 的「修改水体」选择「调整水面面积」并填 400 cm²，提交后被现有水量的容量规则拒绝。改用补水 0.8 L 成功，初始 18.00 L 变为 18.80 L。撤销和重做后查看「养分与有机质」并保存。 | UI-031 至 UI-034 |
| 当前布置另存 | 在世界库选「将当前布置存为预设」，输入名称。实际提交按钮为「保存名称」。成功后该个人预设可从另一标签的下拉框选到。复制现状另有独立表单，本轮在该表单取消。 | UI-035、UI-036、UI-042 |
| 空白环境 | 空白浅塘 W03 起始干涸，投放初始生物按钮禁用。补水 18 L 后加入一组初始生物。空白林下 W04 初始有石块和场景底图，也能一次加入主题的初始生物。 | UI-037、UI-038、UI-066、UI-067 |

到此停在已编辑的正式副本。产品现有调整入口是石块、水体表单和主题初始生物组合。素材分类、搜索、画笔、逐物种放置及移除没有能执行的对应界面。

## F03 试运行、丢弃与采用

| 步骤 | 操作和结果 | 证据 |
| --- | --- | --- |
| 从编辑进入 | W01 处于编辑暂停，点「试运行」。原来的保存和编辑控制换成试运行工具，画布出现副本标识。 | UI-022 |
| 推进并查看 | 选 10× 后点「推进 20 模拟秒」。界面报告本批增加的时间及生态变化。倍率选择和实际推进是两步。 | UI-023 |
| 返回 | 在 W01 看过「采用结果」与「另存为世界」的独立确认／输入面板后均取消，再点「丢弃副本」，返回原世界的编辑暂停。 | UI-024、UI-025、UI-026 |
| 实际采用 | 仅在独立的 W03 中另开试运行，推进 60 秒后点「采用结果」「采用并保存」。提示说明目标世界，采用后回到 W03 正式编辑状态，保存相应进度。 | UI-039、UI-040 |
| 区分暂停语义 | 从生活中进入编辑后，「完成编辑，开始生活」回到运行。先人工暂停再进编辑时，按钮改为「完成编辑」，完成后页脚提示保留原先手动暂停。 | UI-027、UI-028 |

UI 提供手动分批推进，没有播放/连续暂停按钮。试运行另存的表单实际打开，未提交。未注入冲突；服务端存在分支基线校验，详见实现图。

## F04 组件、组合和闲置

| 步骤 | 操作和结果 | 证据 |
| --- | --- | --- |
| 起点 | 原始布局启动后仅有生态画面。鼠标离开后的时钟覆盖可以先于用户看见生态场景出现。 | UI-001、UI-081 |
| 设置 | 打开「组件设置」。默认跟随编辑器，可选保持画面、时钟、自定义文字。选择文字显示后出现 30 字字段。在下拉框选择固定观察林下后保存。 | UI-008、UI-050、UI-051 |
| 闲置与聚焦 | 保存自定义闲置文字以后实际等待出现覆盖，再将场景聚焦。模糊覆层消失，生态画面恢复。 | UI-052、UI-053 |
| 三种组合 | 用原生工作区保存入口准备「生态画面、时钟、环境信息」的组合、自由和混合布局。三者是同一个系统面板中的组件，独立时钟在自由模式下是独立卡片。此次未从系统托盘勾选组件。 | UI-054、UI-055、UI-056 |
| 实际调整 | 右键环境信息卡出现「调整这个组件」。通过原生指针选它，随后拖动环境信息卡以改变相对位置。组的包络随之变化。 | UI-057、UI-071 |
| 前台与面板 | 切编辑器到浅塘 W02 时，绑定林下 W01 的桌面面板仍渲染林下。关闭编辑器后面板仍可见。 | UI-064、UI-065、UI-073、UI-058 |

布局直接在桌面操作，设置窗口提供来源、闲置选项与手势说明。透明区域在原生面板外缘的系统级点击穿透本轮没有验证。

## F05 检查点、关闭重开和布局续接

| 步骤 | 操作和结果 | 证据 |
| --- | --- | --- |
| 世界阶段 | W01 调整后「保存世界」。右栏底部「画面与存档」展开后可点「读取检查点」。确认文字说明会替换当前状态并结束撤销。读取后页脚提示已加载。 | UI-019、UI-020、UI-021 |
| 世界库阶段 | 在 W03 的世界库归档 W02，确认文字说明保存并停止它的后台推进。展开归档分组可选恢复，完成后切回 W01。 | UI-043、UI-044、UI-045 |
| 失败与重试 | 复用项目的故障复现办法，临时阻塞本次隔离数据的世界保存路径。真实「保存世界」显示失败，撤回阻塞后同一入口保存成功。 | UI-068、UI-069 |
| 窗口与进程 | 先点编辑器自己的「关闭」，仍在桌面看到组件。进程级「保存并退出」通过其原生处理入口执行。之后用同一隔离数据和新的 WebView2 配置重开。 | UI-058、UI-061 |
| 读回关系 | 重开后检查当前林下、含四个隔离世界的世界库、面板的绑定和混合布局。观赏和编辑可看同一个世界。组件也可独立绑定另一世界。 | UI-062、UI-063、UI-065、UI-073 |

检查点是世界数据。面板组合、位置与来源绑定属于独立的工作区配置。此次只有采集副本经历归档、故障和冷启动。
