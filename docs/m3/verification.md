# M3 世界库、后台运行与桌面整合

## 本轮交付

| 计划 | 实现 |
| --- | --- |
| M3-01 世界库与预设 | 从林下、浅水池塘、空白或个人预设新建。世界可命名、复制现状、归档和恢复。归档保留已提交的检查点。 |
| M3-02 世界调度 | 前台和非归档后台世界有独立状态与暂停原因。切换修改视图绑定并保留运行代次。正常推进时共享一个 Windows 活跃时钟采样，按世界分别计算步数。 |
| M3-03 试运行 | 支持整套模型的加速批次、丢弃、合规采用和另存为独立世界。采用核对分支起点，先写有效检查点，再更换正式运行代次。 |
| M3-04 与 M3-05 观察和布局 | 保留已经确认的组件组合、自由摆放、吸附和组内离开覆盖。经组件设置固定观察世界后，编辑器的世界切换不改变组件来源。覆盖停止场景动画，并保留暂停或保存失败提示。 |
| M3-06 屏幕放置 | 面板保存显示器标识和工作区相对位置。窗口失去可达的标题区时可在当前屏幕找回。恢复使用当前工作区域与 DPI。 |
| M3-07 错误处理 | 区分不可读、版本过新与从上一个检查点恢复。坏的个人预设报告警告，其他预设仍可用。试运行冲突时可另存，磁盘保存失败时保留可重试的分支。 |
| M3-08 季节呈现 | 林下和池塘按模拟日历映射连续的自然色温，林下植被另有受损和生物量表现。真实日照和桌面北京时间维持各自的职责。 |

## 关键语义和限制

- **个人预设**保存岩石或水域布置、水量和地点。初始化采用该主题的起始生物与资源配置。模拟时间重新从零开始。**复制现状**和**试运行另存**保留完整生态进度与随机状态，生成独立世界并暂停。
- 空白林下有底材和可移动的石块，空白浅塘起始为干床。可显式加入一次主题示例生物组合。引入的生物与起始有机质进入边界账本，干床需先补水。自由地形绘制、动态分合池和逐物种选放继续作为编辑能力扩展。
- 当前配置有一个桌面面板，生态图与环境信息共享一个世界来源。大观赏窗跟随编辑器的当前世界。其他世界后台藏在世界库，可切换继续观察。
- 系统电源状态变化会重建每次采样的活跃时间基线。主动暂停、归档、离线和系统睡眠都停止对应世界的推进。普通清醒积压有独立待处理步数，后台队列按总预算轮换执行。
- 保存并退出尝试提交所有已加载的正式世界。若后台保存失败，应用继续运行并给出错误；已提交的检查点可直接恢复。不可读的原文件保留，临时显示状态不能覆盖它。若新世界检查点已经提交、但更晚的名称或选择写入失败，完整检查点仍可从世界库发现。
- 屏幕位置使用可逆默认。显示器不再可用时回到当前主屏。未保存的位置继续读取原布局语义。物理副屏热拔插与跨实际混合 DPI 的体感仍需设备矩阵验收。

## 已执行检查

- Windows 原生调试版成功构建，`scripts/windows.ps1 -Mode test` 共通过 68 项 Rust 测试，其中生态内核 23 项、世界运行层 29 项、Windows 应用 16 项。核心回归覆盖旧检查点、重复编辑、预设复现、后台与前台隔离、模拟睡眠边界、试运行代次冲突和写入失败重试。
- TypeScript 与 Vite 构建通过。`node --test apps/desktop/tests/layout.test.mjs` 通过 13 项，覆盖组合、自由、混合、吸附、前后层次与可选显示器位置迁移。
- Edge 对照固定同一个权威生态状态与日照相位，只更换模拟日历，验证两个主题都随日历改变配色。省略季节时，新旧版本两主题的 480 × 270 画面逐像素一致。 [季节画面对照与数据](season-render.md)
- 两次隔离的 Windows 原生启动验证了预设新建、复制、归档恢复、后台推进、试运行采用与另存、固定桌面世界和准确恢复最终检查点。不存在的显示器标识分支在本机 150% 缩放下也完成了原生位置恢复。 [原生流程及证据](windows-native-smoke.md)
