# M3 季节画面验证

在本机 Edge 158.0.4370.33 的独立临时配置中检查林下和浅塘。使用 Rust 生成的林下种子 `1206` 和浅塘种子 `2729` 初始快照。每个主题的四个小图读取同一份场景资源、生物状态和正午日照相位 `0.5`，只替换核心日历的模拟第 20、98、193、285 天观测。边缘抽样尺寸为 480 × 270，测试启用减少动态效果以固定帧。 [四季画面对照](../../.local/m3-season-render/season-comparison.png) · [原始检查结果](../../.local/m3-season-render/checks.json)

对照里冬季光色偏冷，林下春夏植被的绿色变亮，秋季蕨类偏暖黄，池塘的环境光和水体表现随季节色值变化。旧模型无季节字段的兼容检查使用同一份 M2 画面检查输入，对比留存的 M2 构建和当前构建。林下与浅塘两张 129,600 像素场景的 RGB 差异均为 0。 [原始检查结果](../../.local/m3-season-render/checks.json)

测试只改变渲染输入中的已计算季节字段，用于验证季节画面来源和无季节字段的兼容性。真实跨季运行、季节物种表现和 Windows 多屏物理缩放需分别验收。
