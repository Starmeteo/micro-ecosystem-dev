# M0 原型验证记录

执行日期为 2026-11-24。使用 100 ms 固定步长、四只鼠妇、两块水分状态与一个可移动石块的 M0 夹具。它用于验证渲染、调度、通信与持久化的合同。林下模型校准及真实地点日照留给 M1。

## 环境及产物

- Windows 11 25H2 x64，构建 26200.9457。Intel Core Ultra 9 275HX。设备枚举包含 Intel Graphics 32.0.101.8332、GeForce RTX 5060 Laptop GPU 32.0.15.9186。
- WebView2 157.0.4341.60，Rust/Cargo 1.100.0 MSVC，MSVC 14.51.36231，Windows SDK 26100，Node 26.1.0，npm 11.13.0。
- Tauri core 2.12.7、CLI 2.12.6、JS API 2.12.5、React 19.3.1、TypeScript 7.0.2、PixiJS 8.23.0。依赖由 [Cargo 锁](../../Cargo.lock) 与 [npm 锁](../../apps/desktop/package-lock.json) 记录。
- Windows debug 原型位于工作区 target/debug/micro-ecosystem-desktop.exe。使用 Vite 8.3.8 生产前端与 Tauri 自定义协议。构建中的静态主 JS 约 563 kB，触发 Vite 默认体积提示，构建通过。

## 原生窗口与后台

调试程序在本机创建三个不同的原生窗口。每个窗口的 decorations 为 false，记录到的缩放参数为 150%。编辑器为 1590×1095、观赏窗为 1230×825、组件面板为 576×405 物理像素。探针调用与托盘菜单共用的显示/隐藏及保存退出入口。

所有区间使用同一世界、同一运行代次。检查点回读后状态一致，运行代次更新，随后保存并退出成功。重新启动可执行文件后，启动日志显示识别到同一测试世界，仍处于保存的暂停状态，停在第 27 步。完整的归一化证据见 [原生探针](native-probe.json)。

## 原生 WebView 画面与输入

首轮实机发现界面有状态读数但画布空白。素材载入改成 WebView 直接解码 PNG 后复测，WebGL 场景可见，保留原生内容安全策略。在 150% 缩放下拖动石块，Rust 接收并提交归一位置 (0.69625, 0.75222)，仍停在暂停时的第 27 步。实机切换夜间预览时，画面按同一构图变暗，权威世界保持第 50 步。 [白天实机画面](editor-day.jpg) · [夜间实机画面](editor-night.jpg)

隔离进程的 WebView 验证在 150% 缩放下读到三视图的实际画布大小分别为 960×540、1204×677、480×270。组件面板在离开后出现模糊和北京时间，聚焦后清除模糊。通过 WebView 发出 25 次幂等暂停命令，本机回执耗时中位数 1.1 ms，95 分位 2.1 ms，最大 2.6 ms。该切片仅测短时 IPC 回执，帧耗时、CPU/GPU 和长时负载需另测。 [WebView 验证摘要](webview-probe.json)

## 本机现代待机 S0

用户通过 Windows 电源菜单手动睡眠并唤醒。相应的 Kernel-Power 506/507 事件间隔为 24.99 秒。原型收到挂起与恢复通知时均为第 642 步，约一秒后的采样为第 652 步。同一个世界、运行代次与运行意图得到保留。早一轮 Windows 待机在旧画面构建上也观察到挂起与恢复均为第 4640 步。

此机在该 S0 路径的数据中，首次收到宿主挂起通知前的长采样间隔里，Windows 活跃计数器仍记录了约 22.50 秒。原型依靠电源事件重建时间基线，实测未将这段累积计入生态步进。宿主恢复通知与系统日志结束事件时间有数秒差异，恢复步骤以宿主收到事件为边界。S4 休眠、缺失 S0 通知以及不同设备的待机行为待独立实测。 [现代待机实机日志摘要](modern-standby.json)

## 能力边界

- 视觉资产含两套逻辑像素网格、28 个独立 PNG 和可编辑的生成源。固定状态的 [两档密度对照](../../apps/desktop/src/render/source/density-comparison.png) 与 [素材说明](../../apps/desktop/src/render/README.md) 可直接审查。
- 本机文件提交使用同目录临时文件刷新后的 NTFS 硬链接发布。原型保留历史检查点。M1 要补可靠的保留策略、写盘压力与不支持的文件系统策略。
- Windows 图形验证范围为本机单屏 150%。100%/125% 与混合 DPI、拔插显示器、GPU 上下文恢复、较弱机型及长时渲染开销待后续实测。托盘动作由原生共享路径验证，实体托盘图标的菜单点击待补测。原生退出时 WebView2 偶尔写了一条窗口类注销诊断，进程退出码为 0。
