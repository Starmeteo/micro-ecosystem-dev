## Windows 原生闭环

- 在隔离目录中通过 WebView 操作新建预设世界、拖动石块、撤销和重做。左、右可通行单元由 23 / 24 变为 24 / 23，编辑时水量保持原值。试运行界面推进 60 模拟秒后可丢弃，正式世界保留原步数与资源。
- 在编辑暂停时保存，第 29 步退出。第二个 Windows 进程打开同一数据目录，同一世界仍停在第 29 步。石块、鼠妇、完整林下资源、随机状态、地点和当前光照相位相同，运行代次更新。 [操作记录](../../.local/m1-native-evidence/closure-20261124-210047-794/checks-begin.jsonl) · [重开记录](../../.local/m1-native-evidence/closure-20261124-210047-794/checks-reopen.jsonl)
- 原生探针依次以 0、1、2、3 个可见视图各观察约 650 ms，同一世界推进了 600、600、700、700 ms。暂停并隐藏后推进 0 ms。 [窗口探针日志](../../.local/m1-native-evidence/lifecycle-20261124-210137-707/trace.jsonl)
