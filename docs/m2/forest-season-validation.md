# M2 林下生态与季节验证

林下季节模型 `forest-understory-seasonal/1` 使用独立的模型版本 4。它保存鼠妇年龄、连续饥饿和干旱计时、繁殖进度和育幼储备，并保存各土壤格的跳虫生物量、蕨类生物量和植物受损程度。已有版本 2 继续使用原来的机理和参数。版本 4 的新世界从第 1 年第 1 天开始，每年 365 个模拟日，空气温湿度随连续的年相位变化。现实日照只提供光相位目标，季节和生物年龄只随累计模拟步进。

## 机理与可观测量

| 过程 | 实现和读数 |
| --- | --- |
| 鼠妇生长、繁殖与死亡 | 摄食同一格的有限落叶。有储备才增加组织和育幼储备，暖湿条件推进育幼进度，幼体物质全部来自育幼储备。衰老、饥饿或持续干旱导致死亡；组织、储备和未完成的育幼储备进入当地凋落物。按个体查询年龄、幼体或成体、组织碳和育幼进度。 |
| 跳虫 | 以土壤格的群体碳库存表达。区分微生物自然周转与跳虫实际取食；取食在微生物剩余量内，部分保留为跳虫生物量，其余进入排出物。跳虫死亡回到当地凋落物。 |
| 蕨类和苔藓 | 以斑块生物量和 0–1 的受损程度表达。两者从同格有限矿质氮、磷和外部碳形成新组织；光照、遮阴和含水率共同改变生长，受损组织回到凋落物。 |
| 边界和损耗 | 土壤供水、溢出和蒸发分别进入水账本。光合作用计入外来碳，矿化及鼠妇呼吸计入碳输出。内部物质转移记在库存，避免把凋落、繁殖或排泄重复计作外部输入。 |

季节气温范围 5–23 °C、相对湿度范围 62–82%，是统一的实验性温带环境。连续供水按每格 2.7–4.3 mL/h 计入外部输入。鼠妇的 14 天最低成年年龄、6 天基准育幼时间、220 天寿命边界、32 个体容量、各生物量转移系数和植物的失水阈值都是实验参数。生命阶段简化为幼体和成体，育幼代表营养分配与发育，植物采用斑块级库存。长周期内持续混养、真实物种的发育时长和自然降水尚待校准。

来源用于确定机制方向和差异。鼠妇微环境会影响行为、存活和发育，单一物种的温度或湿度系数需另行校准。[鼠妇微环境实验](https://pubmed.ncbi.nlm.nih.gov/26261446/)、[鼠妇育幼条件实验](https://www.sciencedirect.com/org/science/article/pii/S1313298915002359)

跳虫对矿化的关系随土壤水分变化。蕨类耐旱性和苔藓复水反应存在不同策略，本预设只选一种植物响应情景。[跳虫土壤微宇宙实验](https://www.tandfonline.com/doi/full/10.1080/00380768.2010.551107)、[蕨类原始宏生态分析](https://pubmed.ncbi.nlm.nih.gov/39344981/)、[苔藓失水和组织性质实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC9314017/)

## 已执行的核心检查

`cargo test --locked -p eco-core` 通过。以下新用例随产品代码执行。

- 18,000 步一次推进和 45 组各 400 步达到相同完整状态。水量与 C/N/P 账本残差绝对值均低于 `1e-7`。
- 从已准备的繁殖、成年和衰老边界条件推进一轮，断言幼体组织来源、稳定个体编号、幼体转成年以及死亡库存原位归还。
- 用相同日照比较冬季和夏季蒸发。对照湿格与干格，验证跳虫取食消耗微生物、蕨类增长、蕨类和苔藓受损、部分生物量返回凋落物。
- 检查春、夏、秋、冬四次切换的边界、跨年温湿度连续性以及长模拟刻度的范围。

上述边界条件经过有意布置以单独验证机理。跨月预设场景、常态 1:1 的体验节奏和季节画面素材仍需专项验收。
