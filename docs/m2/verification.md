# M2 浅水池塘与林下生态验证

池塘预设以固定步长在 Rust 推进。React 编辑器以带世界代次、编辑修订和命令编号的指令提交修改，观赏窗口和桌面组件读取同一权威状态。新林下预设启用季节、鼠妇阶段、跳虫和植被斑块。既有定义沿用自己的计算版本。真实地点日照只更新世界的光照目标，日历随各世界的模拟步数推进。 [池塘模型](../../crates/eco-core/POND.md) · [林下与季节](forest-season-validation.md)

## 无界面对照

`scripts/windows.ps1 -Mode pond-replay` 运行固定种子 `2729`，固定步长 100 ms。构建后可直接运行 `target/debug/m2-pond-replay.exe` 获取纯 JSON。昼夜目标起始于相同的日相，夜间组需要先对齐目标，因此夜间累计有少量过渡光合。 [原始输出](pond-replay.json)

| 对照 | 观测 |
| --- | --- |
| 初始几何 | 2,400 cm²、18 L、平均水深 7.50 cm，单池一份水质 |
| 补入与排出各 0.80 L，水面调为 2,000 cm² | 进出水分别记账，18 L 对应水深 9.00 cm，出水携带充分混合的溶氧、矿质和悬浮藻 |
| 白天目标运行 2 模拟小时 | 溶氧 8.54 mg/L，累计光合产氧 20.17 mg |
| 夜间目标运行 2 模拟小时 | 溶氧 7.90 mg/L，累计光合产氧 0.04 mg |
| 夜间开始时加入 2,500 mg C 碎屑 | 溶氧降至 1.28 mg/L，水蚤由 48 降至 40，微生物和分解累计耗氧 166.57 mg |
| 排空、再补入 0.80 L | 干床无浓度、无活动物，复水后体积和溶氧恢复可查，动物未重新生成 |
| 两个不连通的水体 | 在主池加入碎屑后，旁池与同种子对照经历 72,000 步仍精确一致 |

三个光照与有机负荷对照的最大水量残差为 0 L，最大溶氧残差小于 `4e-12 mg`，C/N/P 各元素的最大绝对残差小于 `9e-11 mg`。这里的数字是模型对照和浮点收支结果。真实水质变化还取决于完整化学过程、现场测量和物种参数。 [池塘参数及适用范围](../../crates/eco-core/POND.md)

### 默认预设 72 小时观测

`target/debug/m2-pond-replay.exe --baseline` 从两个默认预设的正午起点运行，每 12 模拟小时采样，使用自然模拟昼夜与世界气候，期间无编辑或额外输入命令。每次采样运行完整库存与状态有效性校验。浅塘水量由 18.00 L 降到 17.45 L。三只虾在 60 小时采样点都还存活，72 小时剩两只。水蚤由 48 增至 60。林下鼠妇仍有四只，枯落物由 2,515.80 降至 1,535.89 mg C。这个固定种子的结果提供了早期变化和资源耗减记录。不同季节、真实物种组合及更长期持续性待测。 [原始输出](preset-baseline.json)

## 界面与 Windows

- Windows 调试版构建成功，工作区 55 项 Rust 测试通过，组件布局 12 项测试通过。隔离存档的 WebView2 实测验证新建、补水、撤销和重做、三种场景视图、试运行隔离、退出及检查点冷启动。 [原生操作及证据](windows-native-smoke.md)
- Edge 受控快照检查覆盖 7.5 cm 水位、2 cm 的浅水与浑浊、干床、240 × 135 夜景、150% 缩放及减少动态效果。对比确认林下幼体变化落在正确个体上，局部植被压力只影响对应区域。 [池塘画面对照](../../.local/pond-render-qa.png) · [林下画面对照](../../.local/m2-forest-life-qa.png)

## 实现边界

- 浅塘编辑器开放一片预设水域的补水、排水、改变面积和加入碎屑。无界面可检查多个独立水域。任意地形绘制、动态改变连通关系和自由建造留待预设及编辑能力扩展。
- 米虾使用个体模型，水蚤使用总库存及整数种群。两者的繁殖都要求现有储备，死亡进入碎屑。水温和溶氧按单池统一计算。画面的水深和遮挡只表达空间、材质与观赏层次。
- 新林下以幼体视觉比例、蕨类／苔藓密度和状态读数呈现生态变化。季节已有温湿度驱动和可查日历，春夏秋冬的完整美术变化留到 M3。
- M2 数值采用公开机制依据和有单位的工程实验默认。真实物种和长期稳定混养需要校准。当前的比较无法验证完整水质、长期群落稳定性或一比一速度下的长期观赏节奏。
