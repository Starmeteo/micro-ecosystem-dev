# R5 贴地木段验收

2026-11-25，北京时间 · C 批的 F03 贴地木段

`.\scripts\windows.ps1 -Mode r5-terrain` 可启动石木体验。打开世界库，从「林下 · R5 石木布置」新建世界。点「内容 → 放置朽木段」，在场景中部选择空地，Esc 可取消。在画布拖动或从「属性」选取后，可水平翻转、移除、撤销和重做。体验世界使用 `.local/r5-terrain/data`，双石体验进程和正式发行版使用各自的环境。

## 实际交付

- 新预设使用 `forest-understory-r5-terrain/1`。初始带一块石头，完整地面可直接摆放木段。原 `forest-understory-r5/1` 读回其原石块布局和装饰木段。
- 木段按 260 mm 参考长度投影到 450 mm 林下画幅，使用独立背层、前层、阴影和装饰纹理。按可见像素和前后顺序选择，移除后由完整底图填补。水平翻转改变外观朝向，地表占格和资源量保持一致。
- 石木共用稳定物件编号与同一撤销历史。每根木段按跨过的地表格占用一排，实际落点须避开石块、其它木段和动物。地表遮阴与庇护重合时采用较强的量值。木段上限四根，实际能放多少受空地约束。摆放、移动、翻转和移除保持现有资源库存。
