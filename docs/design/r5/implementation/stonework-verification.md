# R5 扁石与小石组验收

2026-11-25，北京时间 · F02 林下结构物批次

用 `.\scripts\windows.ps1 -Mode r5-terrain` 启动隔离体验。在「世界库 → 从预设新建」选择「林下 · R5 扁石与小石组」，从「内容」放置扁石、两石组或三石组。悬浮时显示各个接地格，遇到占用会变色，确认后由 Rust 校验。点击石组中的任意一块可选中整组，再移动、翻转、移除、撤销或保存。

## 本批实现

- 新预设的模型定义是 `forest-understory-r5-stonework/1`。扁石、两石组、三石组的参考长度或跨度分别为 40、100、140 mm。各有独立石体和短接触阴影，共六张 PNG。原林下场景层保留。 [可重复生成的素材源](../../../../apps/desktop/src/render/source/r5_stonework.py)
- 每组只有一个稳定身份。实际地表占用按各块石头的接地点计算。石头之间的空格仍可通行，组的包围框外观只用于显示。首版每世界可放至多八件 F02，地面空间和动物位置会限制有效落点。
- 扁石和小石组参与原林下的遮阴、庇护、蒸发和通行计算。低矮石材使用较弱的邻域遮阴与庇护参数。已有覆盖重叠时取较强值，布置修改保持水和 C/N/P 库存。试运行、保存、重开和新预设均保存整组身份、规格、位置及朝向。
