# R5 B 开发版与验收

2026-11-25，北京时间 · 用户确认 **B，原生样板加双石编辑**

## 体验路径

从仓库运行 `.\scripts\windows.ps1 -Mode r5-dev`。托盘打开「世界编辑器」后，从「世界库 → 从预设新建」选择「林下 · R5 石块布置」。点「内容 → 放置苔斑岩石」，在场景地面落下第二块。可以拖动、在「属性」中翻转或移除，再测试撤销、重做、试运行、保存重开。关闭单个窗口回到托盘。此模式从 `.local/r5-dev/data` 读取和保存世界。

`.\scripts\windows.ps1 -Mode r5-preview` 打开隔离的两主题样板。切换主题会同步到实体组件窗。工作台的石木摆放和虾姿态由样板控制，供观察素材接触、遮挡和水线。正式浅塘的显示采用新虾精灵、统一体长和整景观察缩放，水体、地形及生物状态由现有世界模型提供。 [分层源和再生成方法](../../../../apps/desktop/src/render/source/r5-art.md)

| 部分 | 实际交付 |

| B · 编辑和试运行 | 可预览落点、确认、Esc 取消、选取、拖动、翻转、移除、撤销、重做。操作在释放或键盘确认后提交。重复命令有回执，过期修订会拒绝。试运行副本可独立调整石块，正式世界继续保有原状态。正式工作台中库预览和打开分开，环境、生物和对象读数分别可达。 |
| B · 保持兼容 | 原季节林下继续使用原定义。新增石块结构仅随新 R5 世界和它的副本保存。世界数据、组件布置分别存储。既有发布程序 SHA-256 与 M4 记录匹配。 |

## 验收边界

- 单屏 150% 为本轮原生实测。其它设备缩放、物理跨屏、透明留白的原生鼠标穿透、长时间多视图性能、系统睡眠和安装包交付仍需专项实测。玻璃使用现有 Acrylic 与 CSS 材质，真桌面背景折射未验证。
- 新世界采用地表格占用。放置预览提示地表区域，具体占用结果由权威回执给出。地面木段在本批作为分层视觉，洞口通行、木段编辑、附着资源和完整浅塘分层替换继续按后续批次处理。
- 原生体验是开发版。既有存档保留原定义；本次验证全部使用隔离目录。
