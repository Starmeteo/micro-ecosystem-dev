## 林下土格基质

在「编辑环境 → 内容」选择原底土、细土或粗腐殖质，然后拖画土格。环境面板可查看各格的当前水量、上限和蒸发倍率。

| 基质档位 | 每格储水容量 | 基础蒸发倍率 |
| --- | ---: | ---: |
| 原底土 | 30 mL | 1 |
| 细土 | 36 mL | 0.85 |
| 粗腐殖质 | 24 mL | 1.15 |

以上是实验参数。蒸发仍会受原有光照、气候和遮阴影响，储水上限同时参与土格饱和度及降雨溢流。改基质当下保留格内水、枯落物和养分。若任一格的现有水量超过目标容量，整笔取消。基质可从岩石、木段和植被下方经过，实际地表遮挡沿用分层画面。

隔离 Windows 编辑器在首行拖过第 4 至第 7 个土格，实测四格都从 30 改为 36 mL，总容量增加 24 mL，格内水量逐项相同。一次撤销恢复四格，重做恢复同一批。隔离 Edge 的实际指针与画布测试另覆盖粗腐殖质、容量冲突、键盘单格绘制和 Esc 取消。 [林下原生画面](evidence/terrain-0.2.2/forest-soil-done.png) · [Edge 操作记录](evidence/terrain-0.2.2/forest-edge-checks.json)

## 浅塘形状

在「编辑环境 → 环境 → 编辑池岸形状」打开 12×12 俯视图，拖画扩展或收回水面，期间预览面积、容量与深度。默认一格 100 cm²。「按比例调整总水面面积」改变每格面积，保留已画出的形状。补水和排水继续使用独立操作。

虚线标记侧视观赏剖面，沿横向保留现有石木、植被和生物的空间锚点。俯视可编辑格影响容量和水深，单池沿用充分混合。笔画若擦掉固定剖面、产生不共边连通的水面、接触另一水域、超出面积边界或容不下现存水量，整笔取消。容量与物质账由 Rust 校验。水位变化后照既有规则检查虾与固体的相交情况。

隔离 Windows 编辑器扩展 4 格，水面从 2,400 增为 2,800 cm²，18 L 保持，水深从 7.50 降至约 6.43 cm。侧视水线实际重新绘制。原生交互验证了保护剖面、分离水格和容量不足三类拒绝，三次都未提交。核心回归另覆盖水域相接拒绝、其他水域隔离、各项库存不变及保存与试运行。 [拖画预览](evidence/terrain-0.2.2/pond-shape-draft.png) · [侧视水线](evidence/terrain-0.2.2/pond-depth-done.png) · [原生记录](evidence/terrain-0.2.2/terrain-checks.jsonl)

580×440 和 1060×730 的隔离 Edge 窗口中，按 Tab 切换控件、用方向键选格、Enter 提交和 Esc 回到场景均通过。测试使用模拟主机。 [紧凑窗口](evidence/terrain-0.2.2/compact-580x440.png) · [操作记录](evidence/terrain-0.2.2/pond-compact-checks.json)
