## 摆放和生态反馈

在浅塘点「编辑环境 → 内容」，选 120、180 或 240 mm 叶片弧长，到池底摆放。三档初始碳库存分别为 30、50、75 mg C。可从画面和「属性」选中各丛，移动、修剪或移除。根系与现有轮生水草和石木共用占位校验。叶片允许与邻近材质自然遮挡，水较浅时以较低的弯曲轮廓贴近池底。

属性显示规格、碳氮磷库存和水中透光比例。该比例反映代表叶深和浑浊度引起的衰减，日夜入射光另行计算。实际生长分配到每一丛，总养分和耗氧仍受水域账本约束。修剪和移除将相应物质转为池底碎屑。干涸保留植物库存，水下增长与呼吸暂停，复水后恢复。现阶段覆盖水体养分、相对水深与透光，尚未建模底泥供养、植株相互遮光和走茎繁殖。 [浅塘模型](../../../../crates/eco-core/POND.md)

旧世界不放入带状叶水草时继续使用原先的轮生水草分配规则。保存带状叶水草后，世界需要 0.2.10 或更新版本读取。
