## 拆层、补画与动画交付

| 工作项 | 后续需要的交付与验证 |
| --- | --- |
| 基底、前中后景 | **需拆层、补画。** 保留远景轮廓、裸土／塘床、非交互碎屑和可替换遮挡层。用独立层完成固定远景、可变日夜／冷暖和光斑。选定光向和色板范围，软雾与水体深度衰减由层色调控制，近中景像素簇按统一网格重画。以树皮顺纹、叶脉、断石面、角形砾石区分材质，留出安静的地表观察路径。交付可编辑图层源、合成预览和裸板自检。 |
| 林下石、木、叶、苔 | **需独立绘制。** 分离主体、落地点、阴影、背面、前缘遮挡、可通行区、附着面，轮廓面积、占地与撞体分别校验。首样只做 F01 可移动石、F03 造型及分层、F09 苔藓外观状态、F12 鼠妇。保留可复用的独立接触阴影思路。木洞画立体遮挡可用静态演示验证；正式让动物从某入口钻入和沿木面走，需要承载面和通行数据支持。 |
| 浅塘木石、浮叶、草与水层 | **需拆层与新画。** 底床、卵石与沉木裸面、贴面苔藓和生物膜、后草与前草、漂浮叶和水下根拆开。用已有水线裁切和盆级水色联动。干露部位补全褪湿表皮，支撑结构在低液位仍有明确落点。水层透色、反光与深度遮挡不写入生物贴图。水面和水下表现必须能分别关闭以检查伪影。 |
| 鼠妇、米虾、两类微小群体 | **需新画。** 先校准鼠妇主体端点及脚部接触点，分别出停驻、走、摄食、隐入遮挡关键帧，体轴跟随承载面。米虾有贴面停驻、移动或摄食与悬泳差分姿态，悬泳无底面影；按已有活动数据决定能否展示。幼体只在有阶段数据及独立美术口径时呈现，画面中一只小虾不能替代阶段数据。弹尾虫与水蚤绘制聚合代表材料，近看可附独立放大形态说明；不为代表点补造逐只 ID、个体比例或历史。 |
| 陆螺、淡水螺 | **需新画、需模型支持、待类群。** 研究版先区分壳宽／壳高、实际壳型、姿态延伸、贴面螺足；正式生产前完成候选物种或功能型选择、食性和收支接口。最终侧视/停驻/缩壳由真实状态驱动；形态板的摆法、花色或软影不能直接移植。 |

## 代表样板与完成条件

建议先完成一张林下样板，采用 **F01 一块石、F03 一段朽木分层、F09 一块苔藓、F12 一种鼠妇**。用同一张场景在石前、石后、树皮上和洞口做对照，不把样板里的摆放和动画当成已接模型。第一批实际可编辑内容先选 F01 多实例。若同时选 F03，先做贴地木段、可解释占地和遮挡，洞内导航和附着资源分后续。浅塘完成同尺度贴面/悬泳缩略样板后，再扩 P01/P02/P13。 [批次与前置](04-content-and-sources.md)

1. **比例和清晰度。** 以 480×270 原生逻辑栅格先做样板，同时仅取「树皮—苔藓—鼠妇」同构裁片制作 960×540 密度对照。两者对齐并记录同样的物理内容宽。先检查中景叶、主石和鼠妇的横向标线，再用无遮挡且对齐主参考平面的中性姿态核对体轴，允许至多 1 个逻辑像素的取整误差。大窗口要见得到背甲和材质，普通小组件先读出湿土、木和石。微小群体在桌面可以只剩微点，2×/4×观察以同比放大附近叶脉、纹理和生物补足辨认。选择辅助标记可独立扩大命中区，实体大小继续按标尺计算。
2. **接触、遮挡与编辑。** 用同一只鼠妇在木前、木上与洞口做可重复的观测位。脚端应贴承载面，洞前缘应遮住经过其背后的体节，换帧时锚点漂移至多 1 个逻辑像素。拖开石木后原位应露出完整基底，影子和绑定的美术斑块按父对象移动，无旧残影。正式闭环覆盖新增、点选、合法／非法落点、Esc、移动、删除、撤销／重做、保存重开和试运行隔离。视觉样板与运行验证分别留证。
3. **真实显示链。** 在桌面组件与观赏窗口记录实际内容宽、CSS px、设备 px、DPR、采样和屏幕缩放，覆盖 100/125/150/200% 与至少一个非整数映射和跨屏切换，捕捉 1×/2×/4×、缩放前后稳定性和边缘闪跳。正式采用更高密度前对比轮廓、动画、显示稳定性、实际帧时间和内存。先做可回退的资源样板，实际收益不足时保留 480 网格和现有低密度备选。
4. **玻璃与画面并排验收。** 浅、深、高频壁纸下核对容器清晰边界、稳定的文字保护底、合成后对比度和 DPI 命中。正常生态画面保留像素簇，边缘高光与光学效果停留在外部控制面。组合或混合布局的闲置遮罩应纳入生态主组件及其组内覆盖项，独立窗口按自身策略。验证减少动效、减少透明、唤醒首击不误触、原生材质降级。网页截图可做外观基准，原生窗口效果和开销留到真实桌面测量。 [R4 玻璃原则](../design/r4-glass-spec.txt)

样板验收前的主要风险是整图对象残留、层级与接触接口不足，以及同屏像素密度不统一。首轮样板只需要工程和美术按契约校准。正式批量扩充要依据获批范围、代表样板结果和已有世界兼容方案。本轮新增本审查报告，生产素材、代码和用户存档未修改。
