## A · 代表画面、标尺和工作台预览

1. **冻结最小尺度合同。** 主参考面采用统一固定投影，选用 450/600 mm 画幅宽、480×270 逻辑网格作为对照。保留 240 的比较，做一处 960 的高密度版本，用同一内容、同一尺寸、同一窗口交叉观察。先记录身体端点、足点和物体主轴，明确本轮只量参考姿态。像素网格、设备采样差异和量测误差分开记录。第一轮建议正侧标尺轴端点与计算值误差各不超过 1 个逻辑像素，动画和斜向另按姿态核对。
2. **完成林下同屏样板。** 补一段裸地和无生物的遮挡底，分出 F01 苔斑石的石体、底面和接触影，F03 枯木分前后面与阴影供构图验证。放一簇 F09 苔藓，以及 F06 两个确有差异的完整叶尺寸。F12 鼠妇以主体 12 mm 定标，分别验证地表接触、攀到高面时不缩小、经过石木前缘消隐。攀登和过洞画面若用样板路径驱动，明确标为动画展示。
3. **完成浅塘片段对照。** P01 石或 P02 木、P08 沉水草、P13 20 mm 虾同屏。保留水面、池底、前景/远景、水下遮挡和浮层光色的控制权。比较贴底与离面，水位升降时检查等长虾的体长不变。独立观察可以有姿态参考，常态微小群体按密度或代表点出现。浅塘设计样板不改变当前混合水体或将视觉位置解释成局部水质。
4. **验证窗口和交互。** 桌面常态以观赏为主。组件启用与组合留在托盘或设置窗，倍率和局部观察放在观赏窗、编辑器。保留直接拖面板、点选置顶、组合/独立/混合和隐形吸附。独立件叠入、分离时用现有短促的轮廓膨胀和收束确认，指针和落点直接跟手。编辑器与观赏保留明确可触达的关闭或返回动作，沿用无系统按钮排。工作台内场景、观察工具、内容抽屉与原位检查器各占布局轨道。宽窗可并排，窄窗收成场景与任务页。2×/4×放大整块景物并裁切。液态玻璃用中性基底和受光边缘表现，玻璃效果在场景外侧。按合成后的背景检查正文至少 4.5:1，符合大字条件的时钟至少 3:1。闲置覆盖应用于同组，独立组件各自显示，选项沿用时钟、文字或保留画面。验收恢复首击不误触编辑。 [R4 材质条款](../design/r4-glass-spec.txt) · [W3C WCAG 2.2 文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

**完成依据。** 提交同一标尺的三套逻辑密度对照与源文件分层清单、两主题原生桌面/观赏截图、工作台普通与最窄任务分面截图、可操作的预览路径。用实际内容宽测量，覆盖桌面常态尺寸与约 600 CSS px 的检查宽度，记录 100/125/150/200% 设备比例、至少一档分数缩放、实际 WebView2 与窗口尺寸。单设备调缩放与物理跨屏证据单独归档。通过窗口移动、按键焦点、Esc、三检查器、停靠闲置、亮暗高频背景、减动效/减透明等检查后，才接受为生产样板。若设备不足，标记涉及的原生条件待测。当前浏览器证据只能作为比较。 [样板美术要求](03-art-production.md) · [Windows 及现有状态](02-engine-and-state.md)

选 480 或 960 取决于同屏的细节可辨程度、物件点选效果及设备测量。960 的单层 RGBA 像素数是 480 的四倍。样板结束前，在同一台机器、同一场景和窗口组合，对照绘制时间、静置开销、内存与多次开关后的释放。M4 的数字只用作旧软件同条件参照。 [M4 性能基线](../../../m4/performance.md)

## B · 工作台接入和 F01 多实例石块

### B1 · 保全状态并接入样板

1. 接入共同显示尺度和观察变换。保留两套 renderer。编辑器读取实时数据，三个检查器各有原位；库中单击只预览，明确打开才切正式世界。固定桌面来源和试运行副本各自有识别。输入草稿、拖动预览、IPC 提交、确认回执和失败重试分开。旧的保存失败保留到同一目标恢复或用户处置。
2. 工作台可切窄版任务分面，抽屉不覆盖场景工具或确认反馈；编辑结束恢复原运行意图。托盘隐藏与编辑窗口关闭按原协议，既有未暂停世界继续推进。复测布局和观察目标，3 个视图绑定同一世界时只推进一次。池塘的生存率、昼夜和资源公式无需为视觉接入调整。

**完成依据。** 原生路径逐条录入既有状态回归，重点有库选中与打开分离、跟随/固定组件、手动暂停和编辑暂停、无任务栏关闭排下的可退出操作、关闭或隐藏不误结束试运行、世界/布局/自动保存消息分离。按真实场景、实时快照和操作结果验收。 [R3 状态对照](02-engine-and-state.md)

### B2 · F01 多实例编辑闭环

1. **定义与状态。** 一个 F01 预设档位起步、至少支持放两块。每块有稳定实例 ID，关联定义 ID/版本及其坐标、尺寸、可编辑朝向和占地。石体的遮阴/庇护采用确定性覆盖规则，避免同格把效果重复乘算。投放预览与权威落点一致，旧单石位置和影响在迁移夹具中作回归。
2. **编辑与试运行。** 做新增、合法/非法落位、选择、移动/支持的朝向、移除、撤销重做。撤销恢复同一实例 ID、占地和状态，拒绝已占用的落点。指针松开或按键确认后才提交；Esc 和失败回执保留原状态。跟踪 `worldId`、`runGeneration`、`commandId`、`editRevision`，相同命令重试和晚到回执不会重复新增或覆盖更新的状态。
3. **存档与兼容。** 让当前格式的单石旧世界继续运行。若启用升级，先保存原始可回读副本，保留栖息地定义、种群/个体、资源、随机状态、环境相位、模拟步、编辑修订与运行意图。验证新状态、检查点体积及失败回退，原版遇到新格式可识别并保留数据。新世界双建同一预设时各自独立。试运行拷贝对象和全部状态，丢弃留原样，另存分配世界 ID，采用继续查正式基线，冲突保留现场。

**完成依据。** 两块石均可独立选、移、删、撤与重做。旧位置、新位置和重叠场景的遮阴/庇护读数、合法落点与选中轮廓相符。移动/撤销不凭空增加质量，两块下的足点和鼠妇遮挡正确，保存重开后对象 ID 与资源相同。覆盖旧档读回、失败重试、损坏回退、多世界互不影响、试运行的采用/冲突和明确更换显示倍率时状态不变。同种子同命令序列能复现。报告写出执行环境、命令、输入数据与结果，沿用现有 Rust、TS、布局测试和回放入口。 [矩阵 F01](04-content-matrix.csv) · [检查点与迁移](02-engine-and-state.md)
