- 已有四个无标准按钮行、透明原生窗口。默认编辑器 1060×730 CSS px（最小 580×440）、观赏窗 720×450（最小 400×268）、桌面面板 384×216（再由宿主按组合调整）、组件设置 420×410（最小 365×350）。编辑、观赏、设置在配置里启用原生 Acrylic，桌面面板通过 WebView 内 CSS 表现；现有深色中性 token、边缘高光与闲置模糊已有实现。前次采集记录 783 CSS px 窄窗仍可操作，但右栏拥挤，错误与字段隔得远。观察窗和编辑器也没有 R5 共用取景框、内容抽屉与原位属性/环境/生物面板。用独立网格轨道实现工作台，窄窗切换场景/任务，保留控件命中面积和滚动可达性。 [窗口配置](../../../../apps/desktop/src-tauri/tauri.conf.json) · [现有材质](../../../../apps/desktop/src/styles.css#L65) · [编辑器断点](../../../../apps/desktop/src/editor/WorldEditor.css#L249) · [采集 O-02/O-05/O-10](../../../../ui-ux-current-state/observations.md)

## 存档边界与最小迁移方案
