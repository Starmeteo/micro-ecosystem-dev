# R5 工程审查结论

2026-11-25，北京时间 · 审查基准为 R5 · 等待确认实施范围

R5 可以作为下一步工程的视觉基准。建议从**林下同屏样板、浅塘水面与虾的对照样板，以及桌面和工作台预览**开始。同屏必须同时看环境、石木、植被和动物。当前差距主要是尺寸口径不统一、角色缺少可信的接触和遮挡，以及可编辑资产和模型的粒度不同。只缩小动物或把两张底图换进去，都无法交付可布置、可保存的生态场景。

本轮新增审查文档和预览检查证据。生产代码、UI、窗口配置、依赖和用户存档未修改。现有发行程序 SHA-256 与前次采集一致，本轮未构建、运行或重新验收生产程序。技术上可启动边界明确的样板阶段，转正式编码需要用户确认，具体生产阶段另有下表所列前置条件。

### 浏览器交互检查

- 2×、4×的场景宽高倍率实测分别为 `[2,2]`、`[4,4]`，浅塘三个局部入口各有不同的平移值，景物和动物一起移动。六项 960 px 标尺显示 `25.6 / 3.2 / 12.8 / 32.0 / 3.2 / 12.8`。构图内每只动物的物理比例仍需在生产素材上量测。 [局部观察](evidence/edge-02-observation.png)
- 展开抽屉后检查器仍独立占位。1440×1080、783×730 与 580×440 均未出现文档级横向溢出。783×730 和 580×440 的文档高度分别达 1543、1564 CSS px，检查器自身也需滚动。工作台窄宽应把当前任务切成独立分面，保留可见的应用、取消和错误反馈。 [展开抽屉](evidence/edge-03-editor-expanded.png) · [783 px 窗口](evidence/edge-04-editor-783px.png)
- 预览可切换浅色、深色和高频背景，闲置模拟可出现覆盖层，唤醒可恢复。形态图弹层按 Esc 关闭后焦点返回原卡片，方向键可切换评审页。资源检查未发现远程 HTTP(S) 加载。DPR 在浏览器模拟，R5 原生 WebView2 的跨屏、拖拽、合成器材质和实际时钟仍待实测。 [浅塘闲置示例](evidence/edge-05-pond-idle-busy.png)

## 现有链路与可以复用的部分

`apps/desktop/package.json` 和 Rust 宿主清单锁定 React 19.3.1、TypeScript 7.0.2、PixiJS 8.23.0、Tauri API 2.12.5、Rust Tauri 2.12.7。`WorldScene` 按主题路由，林下用 Pixi，浅塘用 Canvas 2D。两条绘制链可先共享尺寸、裁切和接触点的计算，在各自渲染器内对照样板。

Rust 的 `eco-core` 和 `world-runtime` 负责世界、资源、命令、试运行与检查点，Tauri 转交输入并管理托盘、原生窗口和休眠信号。桌面布局与固定观察来源有各自的持久状态。工作台可以复用实时快照、现有编辑/试运行入口、独立布局、窗口和系统电源管理。隐藏全部窗口仍由运行意图决定是否继续，睡眠和程序离线均不补算。北京时间、地点日出日落和过渡继续走现有时钟链。在审查样机中看到设备本地日期属于预览行为。 [代码入口和 R3 约束对照](02-engine-and-state.md)

生产语义中有实施前要兜住的缺口。目前缺少库中单击专用的独立预览，点击世界行可直接切换；字段值和部分提交反馈由现有控件就地管理；单石拖动和现有撤销仍以特定字段为主。R5 工作台应分别表示当前正式世界、库中选中记录、桌面固定来源、试运行副本及各自失败回执。四者不得因抽屉重排而合并。保存世界、保存布局和后台自动检查点按目标与操作分别显示结果。 [状态对照](02-engine-and-state.md)

## 优先级与阶段判断

| 优先级、责任 | 问题与影响 | 处理与可先做的工作 |
| --- | --- | --- |
| 生产接入前置 · 美术 | 两张底图仍包含整块木石、黏连苔藓和前景阴影。移走时会留残像、遮错动物。形态板也没有可直接使用的透明帧。 | 以构图作为参考，补画裸底和分层素材，先用代表片段检查大小、前后、足点和隐藏区域。 [制作证据](03-art-production.md) |
| 首批可编辑物件前置 · 工程 | 一块石的命令和存档更新不足以覆盖多对象叠加、撤销和试运行。 | 先校验两块石的状态、资源、摆放失败与旧档加载；前端可先完成含多对象的静态交互样板。多物件采用后整份状态必须一致。 |
| 原生交付前置 · 工程 | 网页材质和布局通过部分检查，Windows 透明背景、合成、命中和跨屏仍待核实；高频背景可降低对比。 | 优先现有宿主、组件三种组合、静态材质和可读性降级。以 R5 build 实测拖动与 DPI，Windows 合成器能力按当前版本证明。 [原生约束](02-engine-and-state.md) |
| 需用户确认 | 本次授权边界及首批可编辑范围将改变交付规模。 | 按实施计划确认“仅样板”或“样板验收后接石块”，同时说明是否把地表木段纳入当前授权。 [可选范围](05-implementation-plan.md#请用户确认的实施范围) |
| 非阻断 · 工程 | 水深和屏幕 y 参与虾的体长；窄窗检查器滚动过多；阶段信息未投影到生物观察。 | 以共同标尺定体长，位置与支撑分开；任务分面减少滚动；在数据合同完成前按真实粒度显示个体与聚合信息。 |
| 非阻断 · 交互 | R5 桌面演示把「全图」、倍率和区域操作直接放在组件上。用户此前确认桌面常态尽量少按钮，以托盘集中入口并支持直接拖拽。 | 正式常态组件保留直接拖动与观赏，倍率和区域控制安排到观赏窗、编辑器，组件启用与组合保留托盘入口和设置窗。拖动时指针跟手，组合变化用现有短促的玻璃边缘形变反馈。 |
| 已修复 · 资料 | 原审查发现独立尺度图缺少描边，九图索引的返回目标缺失。 | 已在 Edge 验证独立尺度图和交互预览都显示六条测量线，也从图库实际点击返回并打开 R5 交互预览。 [复核记录](03-art-production.md) |
