# M4 固定生态长跑验证

Windows 构建 26200、Intel Core Ultra 9 275HX、Rust 1.100.0 MSVC 优化构建。2026-11-24 运行完整方案耗时 100.49 秒，其中两个 60 模拟日的基线分别耗时 94.48 秒和 5.03 秒。这些耗时来自无界面计算，桌面常态资源指标另测。 [原始证据](long-run-60d.json)

## 基线输入与检查

| 场景 | 固定输入 | 实际检查 |
| --- | --- | --- |
| FIX-FOREST-BASE | `forest-understory-seasonal/1`，模型 4，种子 1206 | 51,840,000 步。校验土壤水量、各碳氮磷库存、有限值、个体状态、出生和死亡记录。 |
| FIX-POND-BASE | `pond-shallow/1`，模型 3，种子 2729，一块浅水水域 | 51,840,000 步。校验水量、碳氮磷、溶氧和生物状态。 |

固定步长为 100 ms。两场景从各自当前预设正午运行，使用模拟自然昼夜和既有季节驱动。期间没有用户编辑、外加水或现实日照目标。每种场景每 6 模拟小时进行一次完整验证，共 241 次。结束时为世界历第 1 年第 61 天，采样记录显示第 59 天冬季和第 60 天春季。初始完整状态、内容定义、随机算法和随机数生成器的初始状态都在原始 JSON。 [执行源代码](../../crates/world-runtime/src/bin/m4-long-run.rs)

物质收支按初始库存加累计输入、减累计输出和当前库存核对。现行验证容差为 `1e-7 + 1e-9 × (初始库存 + 累计输入 + 累计输出)`，各项沿用各自单位。两场景的 241 个检查点均通过。

| 残差绝对值最大值 | 林下 | 浅塘 |
| --- | ---: | ---: |
| 水量 | 1.389 × 10⁻⁶ mL | 1.332 × 10⁻¹¹ L |
| 碳 | 3.534 × 10⁻⁶ mg | 3.949 × 10⁻¹⁰ mg |
| 氮 | 1.369 × 10⁻⁷ mg | 8.065 × 10⁻¹² mg |
| 磷 | 2.004 × 10⁻⁸ mg | 1.330 × 10⁻¹² mg |
| 溶氧 | — | 1.107 × 10⁻⁹ mg |

两个模型分别在 0 小时和 1,434 小时序列化完整状态，再将每段 6 小时按一批和六批分别推进。同一平台与构建下，状态、账本、待处理过程和随机进度比较相等。此为完整状态编解码与推进验证，Windows 实际存档故障恢复另有验收。 [原始证据](long-run-60d.json)

## 干预与隔离

- 在双水域的主池加入 2,500 mg C 碎屑，账本立即记录输入。推进 24 小时后排空主池，再经过 24 小时干床状态并补入 0.80 L。干床的溶氧浓度为空，复水后实测 10.76 mg/L，虾和水蚤仍为零。复水量在账本记为边界输入。旁池完整状态与未干预对照完全相同，包含库存、计时器和随机状态。
- 两个主题通过正式 `WorldRuntime` 交错步进。手动暂停浅塘期间，林下独立推进 9,600 步。随后编辑暂停林下，浅塘独立推进 4,800 步。每次暂停的世界都保留快照和资源账本。视图切换和系统挂起另由原生流程验证。

## 观察到的生态限制

- 林下由 4 只鼠妇降至 2 只，累计 2 只死亡、0 只出生。枯落物由约 2,515.80 mg C 降至 228.48 mg C。累计土壤水输入 249,268.17 mL，累计输出 249,046.40 mL。
- 浅塘初始 3 只虾，72 小时采样剩 2 只，84 小时采样首次为零。干涸尚未发生。60 天时剩 7.78 L 水、水蚤 73 只。当前预设持续保有虾的目标仍需校准，采样结果只覆盖这一种子和环境。
- 这次验证的是固定步长、库存和边界处理。真实生境适用性、其他种子下的种群分布与更长的建模周期仍待试验。 [模型范围与参数来源](../m2/verification.md)

## 复验

在已初始化 C++ x64 编译环境的 PowerShell 运行以下命令。若使用项目的本地 Rust 工具链，先按 `scripts/windows.ps1` 的方式设置路径。

```powershell
cargo run --locked --release -p world-runtime --bin m4-long-run -- 60
```
