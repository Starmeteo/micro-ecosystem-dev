# Windows 真实现代待机复测

本机支持连接网络的 S0 低功耗待机。用户用 Windows 电源菜单手动进入睡眠，然后唤醒。正式场景用发布二进制和隔离数据，测试时所有应用视图均隐藏。林下是未暂停的前台绑定世界，浅塘作为后台世界保持编辑暂停。 [原生与系统事件](standby.json)

| 本机检查 | 结果 |
| --- | --- |
| Windows 内核电源 506 到 507 | 间隔 21.560 秒 |
| 林下在宿主挂起、恢复事件之间 | 世界 ID 和运行代次相同，两次均为第 373 步 |
| 已暂停的后台浅塘 | 两次均为第 0 步，保持暂停 |
| 恢复约一秒后 | 林下到第 383 步，浅塘仍暂停 |

本机通知是在唤醒附近才由程序处理，宿主日志中两条通知只相隔 27 毫秒。实际睡眠时长取自 Windows 内核事件。对应代码在通知发生时重建活跃计时基线。恢复后从隐藏 WebView2 发出退出命令的 CDP 调用超时。测试驱动随后清理了自己的隔离进程，保留已采集的时间证据。同一版本的正常保存退出已在其他原生场景验证。睡后通过托盘唤出窗口、S4 休眠及其他设备的待机路径尚待实测。 [恢复与正常退出实测](recovery.md)

复验使用 `pwsh -NoProfile -File .\scripts\m4-native.ps1 -Mode standby`。见到 `M4_STANDBY_READY` 后，手动睡眠并唤醒。唤醒后可从系统托盘展示测试面板，使 WebView2 接受测试结束命令。脚本只启动隔离实例，已有应用实例时会停止。
