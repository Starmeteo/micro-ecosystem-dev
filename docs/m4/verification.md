## 已知边界

- 同种子试验中，浅塘于 78 至 84 模拟小时之间失去最后一只虾。60 日时仍有 73 只水蚤和约 7.78 L 水。原始长跑保留这项结果，预设的个体长期适配需要单独校准。林下、浅水池塘均为有明确过程和资源账本的功能型实验模型。
- 自动检查点默认每 120 秒清醒时间处理发生变化的世界，且分散到不同调度轮。可恢复的是最后一份成功发布的检查点。仍未完成的活跃时间积压不会拿来补算离线生态。健康的手动版本、历史损坏文件和最近可读的两份自动版本都保留。
- 本地验证使用单屏 150% 缩放、已有 WebView2 Runtime 和一套 GPU 驱动。M3 已通过失效显示器标识的原生回退，物理接拔或跨不同 DPI 的使用、较弱设备的长期占用、S4 休眠、断电及缺少 WebView2 的安装环境仍需相应设备复测。
- 实际睡眠后的退出自动化出现隐藏 WebView2 的 CDP 超时。已采集的挂起、恢复与后续运行时钟可核对，睡后窗口唤出体验仍待复测。正常启动和退出已分别由发行版及已安装的应用验证。
