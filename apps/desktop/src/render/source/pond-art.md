# 浅塘像素素材

绘制日期 2026-11-24。原创构图与像素源见 [pond_art.py](pond_art.py)。用 Python 和 Pillow 执行该文件，重建 assets/pond/v1 中 13 张 480×270 逻辑画面所用的独立 PNG。

作品从 REF-01/02 取小型动物与植被的色彩分离，从 REF-03 取斜向沉木和砂石，从 REF-06 取水面断续高光，从 REF-07/08 取昼夜冷暖与低对比远景。参考原图未导入运行视图，也未沿用其人物、大型鱼或建筑元素。

远岸、床面、石块、沉木、岸边植被、附着物、光斑、水草和虾都可单独替换。模型水深移动边界裁切和水线。水草用多簇与现有生物量呈现，水蚤约每 6 只显示 1 个代表点，最多 32 点。虾按个体 ID、位置、朝向和活动取帧。光照和浑浊统一作用于同一连通水域。水纹、光斑、景深及游姿微动属于视觉表现，氧与溶质由该水域统一的模型状态表示。
