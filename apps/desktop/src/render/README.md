# 林下视觉样板

这是 M0 的原创固定构图。取用 REF-01 的局部生物对比、REF-02 的附着苔藓与朽木层次、REF-03 的地面深浅、REF-04 的前景遮挡和 REF-08 的冷暖空间组织来检视画面。包内原图未用作贴图或像素来源。

## 可编辑源和导出

[构图与像素源](source/forest_art.py) 保存调色、形状组、苔藓团块、蕨类叶片曲线、石头岩面和鼠妇帧。assets/d1 和 assets/d2 各自导出独立 PNG 图层。修改源后可重复生成两套资源，游戏运行只读取导出的 PNG，Pillow 只用于美术工具。

运行 `python apps/desktop/src/render/source/forest_art.py --comparison` 可重建资源及[双密度对照](source/density-comparison.png)。两套像素密度直接在各自的整数像素网格绘制，共用构图、锚点与轮廓，细密笔触依密度缩减。对照图使用固定石头和动物位置，分别以 480×270 和 240×135 物理像素显示，保留了相同对比条件。

| 图层 | 作用 |
| --- | --- |
| `sky`、`trees` | 远处光隙、树干、林冠和灰绿色景深 |
| `soil`、`wood`、`moss`、`foliage` | 独立的地表平面、朽木与菌体、附着及地表苔藓、中景蕨类与枯叶 |
| `contact`、`rock` | 可移动石头及其接触阴影，以底部同一锚点放置 |
| `woodlouse-0/1/2`、`woodlouse-shelter` | 行走足部动画及躲藏姿态，保留节段、轮廓与触角 |
| `front`、`light` | 最前方遮挡和独立日间光斑 |

## 画面与验证边界

- M0 初选 480×270 作为大窗口默认；240×135 可直接对照迷你视图的生物轮廓和纹理。对照图中石头、朽木和鼠妇轮廓在两套源中都可分辨，低密度蕨类叶脉合并明显，长时间观赏的背景细节优先采用高密度。真实 DPI 下的效果以目标机截图为准。
- 画布保持宽高比。设备物理像素可接近整数放大时优先整数采样，其余尺度使用最近邻，允许缩小时略去个别细节。位置和拖动命中按同一个画布矩形归一化，布局和素材密度变化不会写入世界坐标。
- 画面消费快照中的坐标、朝向、活动和相位。视觉循环切换鼠妇足部帧，支持降低动态效果。石头拖动预览只存在于视图，抬起后请求宿主提交，Escape 或捕获丢失时取消。生态资源、行为决定和世界时间由 Rust 负责。
- M0 的固定植被、枯叶、菌体、超比例鼠妇和日光光束用于验证构图、遮挡和轮廓兼容性。M1 接入实际模型数据后再确认生物比例、接触范围、物理占地以及光照与空间反馈。
