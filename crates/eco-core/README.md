# 林下 M1 内核实验

`forest-understory/1` 是首个林下预设，模型版本为 `2`。`forest-fixture/1` 继续使用版本 `1` 的示例逻辑。两者的存量、随机数状态和昼夜相位均随世界保存。推进只接收固定步数，环境输入来自世界状态。适配器负责现实时间、暂停和窗口。

R5 V14 `forest-r5-composed/1` 支持一笔在不同土格投放真实落叶和在可通行地表按数量投放成年鼠妇。活体地表苔藓斑块持有所在土格原有库存的份额。移植转移这份库存，修剪转入当地枯落物，取出记为外部输出。 [R5 编辑验收](../../docs/design/r5/implementation/editor-followup-verification.md)

V14 基质刷可按格设置原底土、细土与粗腐殖质，使用 30／36／24 mL 的实验容量和 1／0.85／1.15 的基础蒸发倍率。编辑保留现有水量与物质库存，整笔容量不够则拒绝。 [基质编辑验收](../../docs/design/r5/implementation/windows-release-0.2.2.md)

R5 根拱和枝根桥分别以 65 × 12 mm 和 90 × 22 mm 表示桥下净空，两端接地点是实心格，成年鼠妇可按原有地表路径通过桥下。碎叶笔刷把一笔输入的 0.1–240 mg C 分配给有效落点，各格通过现有枯落物账本参与取食和分解，整笔编辑一次撤销。 [通行和碎叶验收](../../docs/design/r5/implementation/windows-release-0.2.18.md)

空种壳与橡实壳作为可编辑地表点缀保存。林下快照提供各土格现存分解者碳，供朽木和树皮菌丝纹饰读取。木材以锚点所在格为显示来源，移到新土格后使用当地读数。 [种壳与菌丝验收](../../docs/design/r5/implementation/windows-release-0.2.19.md)

## 预设、空间和资源

- 地表为 12×4 格，步长 100 ms。动物和石头使用视景投影坐标。区域宽高、幼体与成体尺度和土体真实厚度目前没有实测换算。土体每格可存水 30 mL，界面两半各汇总 24 格。土水存量除以储水容量得到饱和度，空气相对湿度在本版本没有单独求解。
- 石头覆盖一个实心格。进出路径按四邻接计算。石头会给周围多格增加遮阴和可躲藏程度，实心格的遮阴值最高且无法进入。一次提交只改变石头位置和从该位置推导的空间条件。旧新位置的库存会在随后的正常步进中变化。
- 初始土水由固定格点分布提供，饱和度为 56% 至 66.2%。降水边界为 0.4 mL/格/h。达到容量时多余水记为径流输出。每格蒸发基值为 22 mL/h，再按昼夜光照、遮阴和当前饱和度缩放。没有暗中补回初始水量。
- 初始林下个体为四只鼠妇功能型。站立位置、朝向、当前行为、保留的方向选择、结构与储备按个体保存。候选格使用实际可达路径、土水饱和度偏好、遮蔽和食物评分。行走速率为每秒 0.017 个投影单位，候选搜索最远五格，决策间隔上限为 4.8 s。步内多个个体对同一格的食物共享有限供给。
- 初始地表库存包括枯叶、微生物、苔藓与可利用矿质 N/P。动物可从本格枯叶摄食，摄食需求上限 0.012 mg C/只/s，其中 39% 进入储备，其余进入排出物。同格枯叶的分解也参与同一步供给分配。分解后的 18% 有机质量进入微生物，其余 C 记向外界释放，N/P 记回矿质库。微生物周转进入排出物库，再按可用底物分解。
- 鼠妇维持代谢每秒最多消耗储备 0.002 mg C，消耗部分的 C 输出，N/P 入排出物库。苔藓只在有光条件下使用同一个矿质库。每固定 1 mg C，从土壤扣除 0.04 mg N 和 0.006 mg P，任何资源不足都限制实际固定量。碳由外部无机碳边界显式输入。M1 枯叶有限，外来枯叶输入为零。

以上速率、比例、初值和行为评分用于观察因果与检验数值。它们处于实验默认状态，未按特定物种或实体场景校准。

## 验证和适用边界

账本逐项计算「初始库存 + 外界输入 − 外界输出 − 当前库存」。水以 mL 计，C/N/P 各自以 mg 计。水只追踪土体液态库及其边界。碳只追踪有机库存与显式跨界通量。内核的检查点有效性容差为 `1e-7 + 1e-9 × (初始库存 + 累计输入 + 累计输出)`，分别应用到各项。基准验收还检查 30 分钟实验各项残差小于 `1e-7`。

在 PowerShell 加载项目 Rust/VS MSVC 环境后执行 `cargo test --locked -p eco-core -- --nocapture`。可核查移动石头前后的遮阴、通路和蒸发方向，也可查看固定驱动和五组随机种子的对照结果、库存残差、输入分批复现、有限枯叶及原子拒绝。运行出的量体和行为只支持已实现的场景。

当前模型没有真实场地微气候或土壤气体求解。土体水的跨区域输运、动物死亡与繁殖、正式物种生活史、水生环境和长期稳定性校准仍需要后续模型。M1 只处理石头的实心占位与周边遮阴/庇护。活体附着表面和其他材料未进入该预设。

## 机制出处

- 鼠妇聚集与生活表现受空气温湿度等微气候因素影响，且受物种和试验条件制约。本模型以土水和遮蔽作为选择输入，实验数据没有直接转为土水阈值或移动速率。[Dixie、White、Hassall，2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4525041/)
- 枯落物碎化、消化和排出可改变微生物利用。作用大小会随枯落物状态与环境变化。[Hassall、Turner、Rands，1987](https://link.springer.com/article/10.1007/BF00378988)
- 土壤微生物可在分解中暂存并释放养分。本模型单独记录微生物生物量和矿质养分。[USDA NRCS 土壤生物资料](https://www.nrcs.usda.gov/sites/default/files/2024-05/Rangeland%20Soil%20Health%20Soil%20Biota%20SD-FS-85b%205-9-24.pdf)
